# wildtype

Type a word and wild things move in. Flowers grow out of the real letter shapes, critters move in, balloons tug on their strings, paint drips, ladybugs land and paper planes loop around the word. Everything is drawn in code and boils like hand-drawn animation.

Effects: Meadow, Critters, Balloons, Doodles, Paint, Bugs, Planes. Click anywhere for a little extra, export your word as MP4 or GIF, or share a link to it.

## Run it

```bash
npm i
npm run dev
npm run build
```

Built with Vite, TypeScript and [GSAP](https://gsap.com). Type set in Fraunces (SIL Open Font License). GIF export by [gifenc](https://github.com/mattdesl/gifenc).
